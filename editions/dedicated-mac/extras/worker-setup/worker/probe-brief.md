# QA worker brief: setup probe

Transport and Computer Use check for a QA worker Mac. Not a product QA job.

- URL: https://example.com (public page, no sign-in)
- Browser: the worker's default browser, brought to the front before any screenshot.
- Check 1: open the URL; record the main heading text (expected: "Example Domain");
  save one screenshot of the browser window named `example-home.png`.
- Check 2: record whether the page shows a "Learn more" or "More information..." link
  (expected: yes). Do not follow it.
- Permitted actions: view only. Do not sign in, submit anything or open other sites.
