# Example brand

A made-up brand that shows the format. Copy this folder somewhere outside the toolkit, rename
it, and replace every file with your own. The full guide is `docs/branding.md` in the
toolkit repository.

| File | Used by | What it holds |
|---|---|---|
| `brand.json` | the exporter | Name, colours, logo, fonts, cover fields and footer |
| `logo.svg` | the exporter | The logo for the cover page (SVG, PNG, WebP or JPEG) |
| `cover.md` | the exporter | Optional cover page layout, with placeholders |
| `brand.md` | the agent | Voice and structure for reports written under this brand |
| `report.css` | the exporter | Optional extra styling (not included here) |
